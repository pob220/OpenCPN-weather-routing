# Unofficial Android 5.14.1-pob220-import-fix

POBsoft (1985-2026). This is a tester build, not an official OpenCPN release.
The runtime patch is backported from the focused upstream PR:
https://github.com/OpenCPN/OpenCPN/pull/5457

Base: Release_5.14.0, 91f3b674366068a6ecd61a5e9aba204bba85f57e.
The functional changes are confined to Android tarball chooser/JNI completion,
host-owned retained plugin bitmaps and deferring a touch-triggered plugin
enable/disable until Qt gesture iteration returns. Original licence and
copyright notices remain. The extra VERSION.cmake conditional identifies this
Android build; desktop version handling is unchanged.

## Verified package and limitations

ARM64 only, org.opencpn.opencpn.dev, host API 1.21, version code 129.
Production OpenCPN signing keys are unavailable. This development package can
be installed alongside a differently named stock package. An in-place update
requires matching certificates. Do not uninstall stock as an automatic step;
its private profile and plugin files would otherwise be lost. Charts can also
reference app-private paths that require explicit migration. A side-by-side
stock-to-development profile migration remains unaccepted until physically
tested. Never promise automatic transfer or return-to-stock data retention.

assets, resources and non-signature META-INF entries must remain identical.

## Reproduction

Use NDK 26.1.10909125, the checksum-pinned v1.2 Android core support archive
(Qt 5.12.2/wxQt 3.1.5), Android API 21 native compiler, JDK 21 and Android
build-tools 35.0.0. Core configure uses the existing Android-arm64;33;arm64
tuple. Set ZLIB_LIBRARY_RELEASE to the NDK sysroot's
usr/lib/aarch64-linux-android/21/libz.so: a desktop /lib/libz.so cached by
FindZLIB cannot link into ARM64. Use a fresh dependency extraction for final
acceptance, and retain full configure/compiler logs. The cache guard verifies
the archive even when already present; llvm-ar replaces the obsolete NDK alias.

The Android manifest input is generated by Android's own tools. The retained
OpenCPN-Android checkout is based on bdbcat/OpenCPN-Android commit
13080822418213b0c199c48711ee220abdf3c7a7. Set the debug variant's versionName
to 5.14.1-pob220-import-fix and versionCode to 129, then run
`:app:processDebugResources` with its retained build setup. Provide its
linked-resources-binary-format-debug.ap_ to the packager. Only its compiled
manifest is used; resource bytes and DEX remain from the verified original APK.
The semantic comparison rejects any manifest change beyond those two fields.

Retain the exact unstripped libgorp.so for symbolication, and strip a copy using
the NDK's llvm-strip. Run package_pob_test_host.py --help for required inputs.
Pass the keystore password through POB_APK_KEYSTORE_PASS; never commit keys or
passwords. The resulting .provenance.json records full committed native source
SHA, input/output hashes, certificate and all changed non-signature entries.

Before installation retain the original APK, private plugins, current profile,
user records and backup hashes. Confirm package/certificate compatibility,
install without uninstall/data-clear, compare persisted records, cold-launch,
test native tarball import with acknowledgement, real reopened interaction and
live disable/re-enable. Separate build checks from physical acceptance.
